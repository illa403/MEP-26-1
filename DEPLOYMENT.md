# Порядок запуску МЕП-26-1

## Етап 1 — демонстрація
1. Розпакуйте архів.
2. Відкрийте `web/index.html`.
3. Перевірте кабінет батьків, студента та старости.
4. Перевірте перемикання статусів відвідуваності й зборів.

## Етап 2 — база даних
1. Створіть проєкт у Supabase.
2. Відкрийте SQL Editor.
3. Перевірте `supabase/schema.sql` і виконайте його в тестовому проєкті.
4. Не вимикайте Row Level Security.
5. До підключення реальних користувачів додайте серверні перевірки зв'язку parent_student та ролей.

## Етап 3 — Telegram
1. Створіть бота через @BotFather командою `/newbot`.
2. Збережіть токен лише в секретах серверного середовища.
3. Налаштуйте HTTPS-адресу Mini App через BotFather.
4. Сервер має перевіряти підпис Telegram `initData` перед довірою до Telegram ID.
5. Для входу за кодом або запрошенням використовуйте одноразові, обмежені в часі коди, які підтверджує староста.

## Етап 4 — захист
- Батько/мати бачить тільки прив'язаного студента.
- Студент бачить тільки власний профіль.
- Староста має окрему роль і журнал змін.
- Не зберігайте токен бота у frontend.
- Не вважайте скриншот або введений Telegram ID доказом особи.
- Перш ніж використовувати реальні дані неповнолітніх, отримайте необхідні дозволи та узгодьте порядок обробки даних із відповідальними особами.
