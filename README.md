# МЕП-26-1 — стартовий проєкт

Білий Telegram Mini App для демонстраційного обліку групи: кабінети батьків і студентів, панель старости, відвідуваність за парами, окремі збори та внутрішні повідомлення.

## Що є в пакеті
- `web/index.html` — адаптивний інтерфейс українською з демо-даними.
- `supabase/schema.sql` — початкова схема таблиць і політик доступу (RLS).
- `bot/README.md` — інструкція для створення Telegram-бота.
- `DEPLOYMENT.md` — порядок запуску.

## Важливо
Це стартовий демонстраційний проєкт, а не готова система для реальних персональних даних. Інтерфейс зараз працює локально з тестовими даними у пам'яті браузера. Він не підключений до Telegram, Supabase чи реальних облікових записів. Не вносьте реальні ПІБ, телефони, відвідуваність або платіжні відомості до публічної демоверсії.

Для реального запуску потрібно:
1. Створити Supabase-проєкт і застосувати SQL-схему.
2. Додати серверну функцію для перевірки Telegram `initData` та одноразових кодів/посилань.
3. Налаштувати суворі RLS-політики та перевірку ролей на сервері.
4. Розмістити Mini App на HTTPS-хостингу.
5. Підключити URL Mini App у BotFather.

## Запуск демо
Відкрийте `web/index.html` у сучасному браузері. Для тестування можна перемикати роль і студента у верхній частині інтерфейсу. Дані демонстраційні.
