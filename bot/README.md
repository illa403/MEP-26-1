# Telegram Bot — підключення

1. Відкрийте https://t.me/BotFather.
2. Надішліть `/newbot`.
3. Назва: `МЕП-26-1`.
4. Оберіть доступний username, наприклад `MEP_26_1_HelperBot`.
5. Токен збережіть у секретах backend, нікому його не надсилайте.
6. Після публікації Mini App налаштуйте її HTTPS URL у BotFather.

Бот у наступному етапі має:
- показувати кнопку «Відкрити кабінет»;
- передавати користувача в Mini App;
- не надсилати персональні відомості в групові чати.

Не вставляйте токен у `index.html` або інші frontend-файли.
